# Події Києва

Дашборд подій Києва — театри, концерти, виставки — з кількох афіш в одному місці.

- події з **Karabas** і **Concert.ua** в одному списку, без дублікатів
- пошук і фільтри: дати, категорія, майданчик
- повторні покази однієї події — одна картка зі списком дат
- ціни в UAH, USD, EUR, GBP за курсом НБУ
- відстань від вашої адреси до майданчика

## Запуск

Потрібен Python 3.12.

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

Перше відкриття збирає події з афіш (~35 с), далі дані беруться з бази.
База оновлюється раз на 24 години або кнопкою «Оновити зараз».

## Як це працює

```
app.py ──► Pipeline ──► scrapers/ (Karabas, Concert.ua)
   │           │
   │           └──► services/db.py (SQLite, events.db)
   └──────────────► читає події з бази й показує їх
```

`Pipeline` запускає скрапери, відкидає минулі події й дублікати
та записує результат у базу окремо для кожного джерела:
якщо одне джерело впало, його старі дані залишаються.

## Структура

| Шлях | Що там |
|---|---|
| `app.py` | Streamlit UI, точка входу |
| `config.py` | налаштування й константи |
| `pipeline.py` | збір і очищення подій |
| `models/event.py` | `Event` — спільна модель події |
| `scrapers/` | один файл — одне джерело |
| `services/` | база даних, курс НБУ, відстані |

## Налаштування (`config.py`)

| Константа | Значення |
|---|---|
| `SCRAPE_TTL_SECONDS` | як часто оновлювати базу (24 год) |
| `KARABAS_LIMIT`, `CONCERTUA_LIMIT` | скільки подій збирати (`None` — усі) |
| `PAGE_SIZE` | подій на сторінці (25) |
| `DB_PATH` | файл бази; його можна видалити — дані зберуться заново |

## Нове джерело

1. Створіть `scrapers/<source>.py` з класом, що наслідує `BaseScraper`
   і повертає `list[Event]` з методу `scrape()`.
2. Додайте його в `Pipeline.default()`. Порядок у списку — пріоритет при дублікатах.
